FAQ

Common questions

Can one app work on both Android and iPhone?

Yes. I build progressive web apps that install on Android, iPhone and computers from a single codebase, which keeps cost and updates low.

Can you add AI to my app?

Yes. Amalnama has an AI assistant built on Gemini through Firebase, and I can add chat, search or automation features to your app the same way.

Will the app work without internet?

It can. Amalnama and Averroes Code both work offline, and I can design your app the same way when it makes sense.

একটি অ্যাপ কি Android ও iPhone দুটোতেই চলবে?

হ্যাঁ। একটাই অ্যাপ Android, iPhone ও কম্পিউটারে চলবে, তাই খরচ ও আপডেট দুটোই কম।
